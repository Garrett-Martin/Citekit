# Citekit

## What it is

A command-line tool for policy debaters to collect and organize research

---

## How to Run

```
python main.py
```

## Current Features

- Add a source manually
- Save sources to 'evidence.json'
- View all saved sources

## Planned Features

- Search by keyword, author, or tag
- Specific policy-style card formmating
- URL scraping
